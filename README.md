# Dars mashqlari

HTML, CSS va JavaScript asoslarini interaktiv mashqlar orqali o'rganish uchun o'quv loyihasi.

## Imkoniyatlar

- **Layout** — Flexbox yo'nalishi, tekislash, bo'shliq va qatorga o'rashni jonli sozlash
- **Animatsiya** — bounce, pulse, spin, slide va shake keyframe animatsiyalari
- **DOM** — hisoblagich, rang almashtirish va ro'yxat bilan ishlash
- Har bir mashq uchun jonli kod ko'rinishi
- O'zbek, ingliz va rus tillari
- Yorug'/tun rejimi

## Texnologiyalar

HTML · CSS · JavaScript · Flexbox · Keyframes · DOM

## Ishga tushirish

```bash
npm install
npm run dev
```
